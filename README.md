## Featured projects

### Real Time Device to Device Wireless Communication System Using ESP-NOW Protocol

A four phase obstacle detection system built on two ESP8266 boards. It combines ultrasonic and PIR sensor fusion with ESP-NOW communication, a PHP and MySQL backend with a dashboard, Isolation Forest anomaly detection, and rule based severity classification. A Decision Tree trained in scikit-learn is deployed on the ESP8266 through micromlgen, so alerts work on the device without Wi-Fi or a server.
